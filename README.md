- ✅ **پشتیبانی از دو پروتکل:** Tor و Psiphon به صورت همزمان

## 🚀 نصب سریع و مطمئن، دستور زیر را در سرور لینوکسی خود اجرا کنید.

```bash
curl -Ls https://raw.githubusercontent.com/mrmarzx/Tor-ML-PRO/main/tor-ml.sh | tr -d '\r' > /root/tor-ml.sh && chmod +x /root/tor-ml.sh && bash /root/tor-ml.sh --install
```

بعد از نصب فقط کافیه بنویسی:

```bash
tor
```

## 📋 آموزش کامل منو و گزینه‌ها

بعد از زدن دستور `tor` این منو براتون باز می‌شه:

| گزینه | نام | توضیح کامل | کی استفاده کنیم؟ |
|:-----:|-----|-----------|------------------|
| `1` | **Full Status** | وضعیت کامل همه لوکیشن‌ها (Tor + Psiphon) شامل CPU، رم، IP، آپتایم و وضعیت Bootstrap | برای چک کردن اینکه همه چیز درست کار می‌کنه |
| `2` | **Start Location(s)** | یک یا چند لوکیشن رو روشن می‌کنه (هم Tor هم Psiphon) | وقتی می‌خوای لوکیشن جدید اضافه کنی |
| `3` | **Stop Location(s)** | یک یا چند لوکیشن رو خاموش می‌کنه | وقتی دیگه به یه لوکیشن نیاز نداری |
| `4` | **Start All Tor** | همه ۶۰ لوکیشن Tor رو با هم روشن می‌کنه | فقط روی سرور قوی استفاده کن |
| `5` | **Start All Psiphon** | همه ۲۸ لوکیشن Psiphon رو با هم روشن می‌کنه | روی سرور متوسط به بالا |
| `6` | **Stop All** | همه لوکیشن‌ها (Tor + Psiphon) + Auto رو خاموش می‌کنه | برای خاموش کردن کامل |
| `7` | **Change Port** | پورت یه لوکیشن رو عوض می‌کنه (بین ۴۰۰۰۰ تا ۶۰۰۰۰) | وقتی پورت پیش‌فرض برات مشکل داره |
| `8` | **Speed / Latency Test** | پینگ و سرعت تقریبی لوکیشن‌های روشن رو تست می‌کنه | برای پیدا کردن بهترین لوکیشن |
| `9` | **View Log** | لاگ آخرین فعالیت‌های یه لوکیشن رو نشون می‌ده | وقتی یه لوکیشن مشکل داره و می‌خوای ببینی چرا |
| `10` | **Set Bandwidth** | محدودیت سرعت (MB) برای یه لوکیشن Tor می‌ذاره | وقتی می‌خوای مصرف ترافیک رو کنترل کنی |
| `11` | **Toggle Sticky Exit** | قابلیت ثابت نگه داشتن IP خروجی Tor رو روشن/خاموش می‌کنه | وقتی به IP نسبتاً ثابت نیاز داری |
| `12` | **Performance Mode** | انتخاب حالت Weak / Normal / Max برای مصرف منابع و سرعت | برای تنظیم دقیق روی سرور ضعیف یا قوی |
| `13` | **Start Auto Balancer** | حالت هوشمند بهترین پینگ رو روی پورت ۴۹۰۰۰ فعال می‌کنه | وقتی می‌خوای فقط یه پورت داشته باشی |
| `14` | **Stop Auto Balancer** | حالت هوشمند رو خاموش می‌کنه | وقتی دیگه به حالت اتوماتیک نیاز نداری |
| `15` | **Uninstall** | کل برنامه و داده‌های Tor/Psiphon رو کامل پاک می‌کنه | فقط وقتی می‌خوای کامل حذفش کنی |
| `0` | **Exit** | از برنامه خارج می‌شه | - |

## ⚙️ آموزش اضافه کردن به پنل سنایی

### روش ۱: اضافه کردن لوکیشن تکی (پیشنهادی)

1. وارد پنل سنایی بشو
2. برو به بخش **Inbounds** یا **Outbounds** (بسته به نوع کانفیگت)
3. یه **Outbound** جدید بساز با این مشخصات:

| فیلد              | مقدار                          |
|-------------------|--------------------------------|
| Tag               | مثلاً `tor-germany`            |
| Protocol          | `socks`                        |
| Address           | `127.0.0.1`                    |
| Port              | پورت لوکیشن مورد نظرت (مثلاً `48180`) |
| User / Password   | خالی بذار                      |

4. بعد تو بخش Routing اینباندتو رو این اوتباند تنظیم کن.

### روش ۲: استفاده از حالت بالانسر(گردش بهترین سرور بین تور و سایفون)

اگه می‌خوای همیشه بهترین لوکیشن به صورت خودکار انتخاب بشه:

| فیلد              | مقدار          |
|-------------------|----------------|
| Tag               | `tor-auto`     |
| Protocol          | `socks`        |
| Address           | `127.0.0.1`    |
| Port              | `49000`        |

---

### مثال کانفیگ Outbound برای سنایی 

```json
{
  "tag": "tor-germany",
  "protocol": "socks",
  "settings": {
    "servers": [
      {
        "address": "127.0.0.1",
        "port": 48180
      }
    ]
  }
}
```

برای حالت بالانسر :

```json
{
  "tag": "tor-auto",
  "protocol": "socks",
  "settings": {
    "servers": [
      {
        "address": "127.0.0.1",
        "port": 49000
      }
    ]
  }
}
```

## 💡 نکات مهم و حرفه‌ای

- روی سرورهای ۱ گیگ رم، بیشتر از ۸ تا لوکیشن همزمان روشن نکنید.
- لوکیشن‌های آلمان، فرانسه، هلند و انگلیس معمولاً پینگ بهتری دارند.
- حالت Sticky Exit بعد از روشن کردن، باید لوکیشن رو یک بار ری‌استارت کنید تا اعمال بشه.
- پورت ۴۹۰۰۰ فقط وقتی کار می‌کنه که حداقل چند تا لوکیشن روشن باشه.
