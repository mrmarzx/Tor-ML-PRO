# 🔥 Tor-ML-PRO

**نسخه بهبود یافته و بهینه‌شده مدیریت چند لوکیشن تور**

یک فورک پیشرفته از پروژه محبوب [Tor-ML](https://github.com/icubaby/Tor-ML) ساخته شده توسط **icubaby**.

این نسخه با تمرکز روی مصرف کمتر منابع، پایداری بیشتر روی سرورهای ضعیف و اضافه شدن قابلیت‌های کاربردی بازنویسی شده.

---

## ✨ تفاوت‌ها با نسخه اصلی

| ویژگی                        | نسخه اصلی (Tor-ML)      | Tor-ML-PRO                     |
|-----------------------------|-------------------------|--------------------------------|
| مصرف رم                     | معمولی                  | کمتر و بهینه‌تر                |
| مناسب سرور ۱ گیگ            | متوسط                   | بهتر                           |
| قابلیت Sticky Exit          | ندارد                   | دارد                           |
| حالت Auto (بهترین پینگ)     | ندارد                   | دارد (پورت ۴۹۰۰۰)              |
| تعداد لوکیشن                | ۵۰                      | ۶۰                             |
| Watchdog خودکار             | ندارد                   | دارد                           |
| بهینه‌سازی تنظیمات تور      | پایه                    | پیشرفته                        |
| کیفیت کد و پایداری          | خوب                     | بهبود یافته                    |
