# 🔥 Tor-ML-PRO

**نسخه بهبود یافته، سبک‌تر و حرفه‌ای‌تر مدیریت چند لوکیشن تور**

این پروژه یک فورک پیشرفته از [Tor-ML](https://github.com/icubaby/Tor-ML) ساخته شده توسط **icubaby** است که با تمرکز روی مصرف کمتر منابع، پایداری بیشتر و اضافه شدن قابلیت‌های کاربردی بازنویسی شده.

## ⚙️ آموزش اضافه کردن به پنل سنایی (نسخه ۳.۷.۰)

### روش ۱: اضافه کردن لوکیشن تکی (پیشنهادی)

وارد پنل سنایی بشو  
برو به بخش Inbounds یا Outbounds (بسته به نوع کانفیگت)  
یه Outbound جدید بساز با این مشخصات:

| فیلد          | مقدار                                         |
|---------------|-----------------------------------------------|
| Tag           | مثلاً `tor-germany`                           |
| Protocol      | `socks`                                       |
| Address       | `127.0.0.1`                                   |
| Port          | پورت لوکیشن مورد نظرت (مثلاً `48180`)         |
| User/Password | خالی بذار                                     |

بعد تو بخش Routing یا بالانسر، از این outbound استفاده کن.

### روش ۲: استفاده از حالت Auto (پورت ۴۹۰۰۰)

اگه می‌خوای همیشه بهترین لوکیشن به صورت خودکار انتخاب بشه:

| فیلد          | مقدار           |
|---------------|-----------------|
| Tag           | `tor-auto`      |
| Protocol      | `socks`         |
| Address       | `127.0.0.1`     |
| Port          | `49000`         |
| User/Password | خالی بذار       |

---

### مثال کانفیگ Outbound برای سنایی ۳.۷.۰

```json
{
  "tag": "tor-germany",
  "protocol": "socks",
  "settings": {
    "servers": [
      {
        "address": "127.0.0.1",
        "port": 48180
      }
    ]
  }
}
```

برای حالت Auto:

```json
{
  "tag": "tor-auto",
  "protocol": "socks",
  "settings": {
    "servers": [
      {
        "address": "127.0.0.1",
        "port": 49000
      }
    ]
  }
}
```

## 💡 نکات مهم و حرفه‌ای

- روی سرورهای ۱ گیگ رم، بیشتر از ۸ تا لوکیشن همزمان روشن نکنید.
- لوکیشن‌های آلمان، فرانسه، هلند و انگلیس معمولاً پینگ بهتری دارند.
- حالت Sticky Exit بعد از روشن کردن، باید لوکیشن رو یک بار ری‌استارت کنید تا اعمال بشه.
- پورت ۴۹۰۰۰ فقط وقتی کار می‌کنه که حداقل چند تا لوکیشن روشن باشه.
